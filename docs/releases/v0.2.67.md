# Packet28 v0.2.67

This release improves linked-task recovery across Claude Code and Codex and hardens daemon, storage, and hook behavior during concurrent agent sessions.

- Recover linked tasks across agent sessions, with continuation coverage for Claude Code and Codex.
- Recover registry checkpoints from authenticated evidence and improve task retention and runtime logging.
- Improve daemon startup, shutdown, readiness, and connection handling under concurrent workloads.
- Fix setup and indexing reliability and validate complete agent workflows through the agent-DX benchmark.
- Update dependencies, including the rustls transcript-collision security fix.
- Split CI validation into focused jobs while retaining the complete release gate and package checks.

## Upgrade

```sh
npm install -g packet28@0.2.67
cd /path/to/workspace
packet28 daemon stop
packet28 setup
```

Restart existing agent sessions after upgrading. Updating the installed package does not replace a running daemon or HTTP hook server; stop any remaining old HTTP server using its verified PID before reinstalling hooks.
